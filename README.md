# GameKit Demo

This repository demonstrates the usage of the **express-gamekit** NPM package.

## Setup

```bash
npm install
npm start  # or node server.js
```

The server will start on port 3000. Open your browser at `http://localhost:3000/` to see the demo UI.

## Overview

- **server.js**: Sets up an Express server and mounts the GameKit toolkit with a demo API key.
- **public/**: Contains a simple HTML page (`index.html`) and client-side JavaScript (`app.js`) that interacts with the toolkit's REST endpoints.
- **.gitignore**: Excludes `node_modules/` and system files from the repository.
